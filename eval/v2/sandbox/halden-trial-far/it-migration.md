# IT: electronic lab notebook migration

The move from the old notebook system to the new cloud platform is in its third phase. So far 212
of 260 active notebooks have been migrated and checked by their owners. The team found 18
notebooks with broken image links, all of which were repaired from the backup archive.

Average page load time in the new platform is 1.4 seconds, against 3.9 seconds in the old one.
Single sign-on went live on September 12 and has had one outage, lasting 35 minutes, caused by a
certificate renewal. The vendor has since added an expiry alert.

Phase four, which covers archived notebooks from 2019 to 2022, is planned for November. The
archive holds roughly 1,900 notebooks, most of them read-only, so the team expects it to go faster
than the active phases.
